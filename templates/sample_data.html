2. Target-schema privileges

After creating or selecting the target schema, use the tested ADMIN connection to grant the package access it needs. This action is idempotent and can safely be run again.

Grants: EXECUTE ON DBMS_CLOUD, DBMS_CLOUD_AI, and DBMS_CLOUD_AI_AGENT.

ADMIN privilege-inspection SQL
SELECT owner, table_name, privilege
FROM dba_tab_privs
WHERE grantee = '{{sample_settings.get('target_schema','DEMO_SALES')|upper}}'
  AND privilege = 'EXECUTE'
  AND (table_name IN ('DBMS_CLOUD', 'DBMS_CLOUD_AI', 'DBMS_CLOUD_AI_AGENT')
       OR table_name LIKE 'DBMS_CLOUD$PDBCS%')
ORDER BY table_name;
